This project is licensed under AGPL-3.0-only. Keeping the copyright in one place
means the licensing can be changed later — for example, relaxed to a permissive
license if that becomes the right call for the ecosystem. If contributors each
retained separate rights, every one of them would hold a veto over that decision
and it could never happen.
